# ふたりの家計：自動同期とスマホで使うための設定

所要時間：20〜30分くらい。どれも無料の範囲で使えます。

## しくみ

- データは **Firebase（Google の無料データベース）** に保存され、ふたりのスマホでリアルタイムに同期されます。
- それぞれメールアドレスとパスワードでログインします。
- 1人目が「共有を始める」と「家計」ができ、招待リンクを開いた2人目が参加します。
  **1つの家計に入れるのは2人まで**で、メンバー以外は読むことも書くこともできません（`firestore.rules` で制限）。
- 電波がないときも入力でき、つながったときに同期されます。

---

## 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com を開き、Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前（例：`futari-kakeibo`）を入れて作成
   （Google アナリティクスはオフで OK）

## 2. ログイン方法を有効にする

1. 左メニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブ →「メール / パスワード」→ 有効にして保存

## 3. データベースを作る

1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは `asia-northeast1（東京）` を選択 →「本番環境モード」で作成
3. 「ルール」タブを開き、中身をすべて消して、このフォルダの **`firestore.rules` の内容を貼り付け** →「公開」

## 4. アプリと Firebase をつなぐ

1. プロジェクトの概要（⚙ 歯車）→「プロジェクトの設定」→ 下の「マイアプリ」で **`</>`（ウェブ）** を選ぶ
2. ニックネームを入れて「アプリを登録」（Firebase Hosting のチェックは不要）
3. 表示される `const firebaseConfig = { ... }` の `{ ... }` の部分をコピー
4. `kakeibo/firebase-config.js` の `export const firebaseConfig = null;` を次のように書き換える

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "futari-kakeibo.firebaseapp.com",
  projectId: "futari-kakeibo",
  storageBucket: "futari-kakeibo.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

> この値はアプリを動かすための「住所」のようなもので、公開されても大丈夫です。
> 誰が読み書きできるかは手順3のルールで守られています。

## 5. スマホで開けるように公開する（GitHub Pages）

1. 変更を `main` ブランチに入れる（プルリクエストをマージ）
2. GitHub のリポジトリ →「Settings」→「Pages」→ Source を **「GitHub Actions」** にする
3. 「Actions」タブで「Deploy kakeibo to Pages」が完了すると、
   `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

> GitHub Pages は無料プランだと **公開リポジトリ** でのみ使えます。家計のデータはリポジトリではなく
> Firebase に入るので、リポジトリを公開してもデータは見られません。

## 6. ふたりで使い始める

1. **自分**：スマホで公開した URL を開く →「共有」ボタン →「ホーム画面に追加」
2. 「設定」→「自動同期」で **新規登録** →「共有を始める」
   （この端末に入れてあったデータも、そのまま共有データになります）
3. 表示された **招待リンクを彼に送る**（LINE など）
4. **彼**：リンクを開く → 新規登録 →「招待された家計に参加する」→ ホーム画面に追加
5. 「設定」→「この端末を使う人」をそれぞれ自分にしておくと、「払った人」が最初から自分になります

## 7. 毎月25日に精算額を LINE で送る（iPhone ショートカット）

1. iPhone の「ショートカット」アプリ →「オートメーション」→「＋」→「特定の時刻」
2. 時刻（例：9:00）を決めて「毎月」→「25日」を選び、**「すぐに実行」** にする
3. アクションに **「URLを開く」** を追加し、アプリの「設定」→「iPhone ショートカット」に表示されている
   アドレス（最後が `#line` のもの）を貼り付ける
4. 毎月25日になると、精算額が入った LINE の送信画面が開くので、**相手を選んで送信** するだけです

送られるメッセージの例：

```
10/25の精算（9/25〜10/24）
彼 → 私：¥47,840
（合計 ¥104,321 ／ 私負担 ¥52,161 ・ 彼負担 ¥52,160）
```

> ショートカットは Safari でアプリを開きます。iPhone では「ホーム画面に追加したアプリ」と Safari の
> ログイン状態が別々なので、**最初の1回だけ Safari でもログイン** しておいてください。
>
> LINE の決まりで、ほかのアプリから勝手にメッセージを送ることはできないため、最後の「送信」だけは手で押します。

## よくある質問

- **パスワードを忘れた**：今は再設定画面がないので、Firebase コンソールの Authentication からユーザーを削除して
  新規登録し直し、もう一人から招待リンク（設定画面に表示）を送ってもらってください。
- **費用は？**：ふたりで使うくらいなら Firebase の無料枠（Spark プラン）に収まります。
