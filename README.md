# As-playroom

## ふたりの家計（`kakeibo/`）

ふたりで生活費を分担・精算するためのスマホ向け Web アプリです。

- **カテゴリごとの負担割合**：家賃・食費などカテゴリごとに「私 ◯% : 彼 ◯%」を自由に設定
- **かんたん入力**：金額・カテゴリ・払った人を選ぶだけ。割合はその支出だけ変えることもできます
- **レシート読み取り**：📷 で撮ると合計金額と日付を自動入力（Tesseract.js による端末内 OCR）
- **毎月25日に精算**：前月25日〜当月24日の分で「彼 → 私 ¥xx,xxx」を自動計算（精算日は設定で変更可）。
  精算メッセージを LINE などに共有、精算済みのチェックも
- **固定費の自動追加**：家賃など毎月の支出を登録しておくと、毎月自動で入ります
- **ふたりだけで自動同期**：Firebase でリアルタイム同期。メンバーは最大2人で、ほかの人はアクセスできません
- **バックアップ**：JSON の書き出し / 読み込み、CSV 出力

### 計算方法

各支出について「払った金額 − 自分の負担分（金額 × 負担割合）」を月ごとに合計し、
プラスなら相手からもらう、マイナスなら相手に払う金額になります。

### 使い方

自動同期の設定とスマホでの使い方は **[kakeibo/SETUP.md](kakeibo/SETUP.md)** を見てください。
設定しなくても、端末内だけに保存するモードで動きます。ローカルで試すなら：

```sh
cd kakeibo && python3 -m http.server 8000
```

テスト：`node kakeibo/test.mjs`
